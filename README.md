# AI 多窗口对话

在一个窗口里并排显示多个 AI 平台的官方网页，输入一次提示词，同步注入并发送给所有已显示的平台。基于 Electron，零 API 费用，沿用各平台自己的网页登录状态。

## 支持平台
DeepSeek、Kimi、智谱清言、千问、ChatGPT、Claude、Grok、豆包、元宝（平台网址与选择器见 `platforms.json`，可自行增删）。

## 运行
1. 安装 [Node.js LTS](https://nodejs.org)
2. 双击 `start.bat`（首次自动安装依赖，使用国内镜像）
3. 在各面板里分别登录一次，之后自动保持登录

排查启动问题：在目录地址栏输入 `cmd` 回车，手动执行 `npm start` 查看报错。

## 使用
- 左侧栏切换布局（1/2/3/4/6/8/9 窗格）与开关平台
- 每个面板顶部：模型菜单、刷新、新对话、复制回答、关闭
- 底部输入栏：Enter 同步发送，Shift+Enter 换行，内置提示词库
- 面板内按 Ctrl+Shift+I 打开开发者工具，便于排查选择器

## 说明
- 网站改版后输入框/发送按钮选择器可能失效，修改 `platforms.json` 即可，无需改代码
- 登录状态与设置保存在系统用户数据目录，不在项目目录内，不会被提交到仓库
- 请自行确认同时使用多个平台是否符合各平台的使用条款
